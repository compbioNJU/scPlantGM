# scPlantGM
`scPlantGM` is a hierarchical and gene module-based annotation framework optimized for plant single-cell data. With high accuracy, biological interpretability and robustness to data imbalance, `scPlantGM` demonstrates strong capabilities to conduct mutiple functions, including **automatic cell type annotation**, **marker reference generation** and **cross-species conservatism analysis** etc.



# Usage
In summary, `scPlantGM` owns three modes based on different reference sources. The user can flexibly choose which mode is more suitable in `custom` argument.
- `None`: users won't provide any custom reference but use built-in reference. The built-in reference includes 11 plant species, such as *Arabidopsis thaliana*, maize (*Zea mays*), rice (*Oryza sativa*) and so on. 
- `Semi`: users will integrate their own reference and built-in reference for comprehensive usage.
- `All`: users will only use their provided reference for prediction.

We will introduce the three modes, seprately.


<details>
<summary>1. Annotate using built-in reference</summary>

In `None` mode, users can directly input the query list for annotation. Please note that the implementation of scPlantGM in `None` mode is currently limited to some tissues of Arabidopis(`Root`, `Leaf`, `Pollen`, `Inflorescence`), Maize(`Root`, `Leaf`), Rice(`Root`, `Leaf`) and another 8 species. The specific tissues included can also be viewed through the following command.
```r
data(Species_Tissue, package = "scPlantGM")
Species_Tissue
```

## Load data
We load `Inflorescence_query` as query list. By default, scPlantGM uses the clustering results generated by [Seurat](https://satijalab.org/seurat/)’s `FindClusters()` function for downstream cell-type annotation, which are stored in the `seurat_clusters` column of the Seurat object.

```r
data("Inflorescence_query", package = "scPlantGM")
```


## Preprocess
Anothor necessary and important object is `seuorder`, which is a vector shows the order of Suerat objects in the list. Sample name or dataset name are recommaded to present the order. Or user can just simply use `c(1,2,3...)` for a quick start.
```r
query <- process_obj(seulist = Inflorescence_query, seuorder = c("SRX13437605"), type = 'query')
```


## Prediction
Run scPlantGM for cell type prediction.
```r
result <- scPlantGM(query, species="Arabidopsis", organ="Inflorescence", custom="None", layer = 2)
```
- `query`: a (list of) query Seurat object that you want to conduct prediction.
- `species`: species of scRNA-seq data. You can choose 11 species in this mode, see `Species_Tissue` object for details.
- `organ`: organ/tissue of species. Available organs/tissues are listed in `Species_Tissue` object.
- `custom` = `None`.
- `layer`: layer of prediction: must be an int (0,1,2...). In `None` and `Semi` mode, user can choose one of built-in layer according to `layer_info_` object of the corresponding species.

The prediction result will be stored as a `data.frame` object as follows:

<details>
<summary>2. Annotate using user-provided and built-in reference</summary>

In `Semi` mode, users need to provide pre-annotated reference datasets. User-provided reference will be integrated with built-in reference for comprehensive annotation. The input requires two lists of Seurat objects: query list (query datasets) and reference list (reference datasets). By default, scPlantGM uses the clustering results generated by [Seurat](https://satijalab.org/seurat/)’s `FindClusters()` function for downstream calculation, which are stored in the `seurat_clusters` column of the Seurat object. Seurat object in reference list also need a column named `scPlantGM.refanno` representing cell type.

## Load data
We load `Inflorescence_query` as query list and `Inflorescence_ref` as reference list.
```r
data("Inflorescence_query", package = "scPlantGM")
data("Inflorescence_ref", package = "scPlantGM")
```

Load table of cell type level of target tissue.
```r
data("layer_info_Arabidopsis", package = "scPlantGM")
layer_info <- layer_info_Arabidopsis %>% 
                dplyr::filter(Organ=='Inflorescence') %>% 
                dplyr::select(Celltype1,Celltype2)
```

## Preprocess
Anothor necessary and important object is `seuorder`, which is a vector shows the order of Suerat objects in the list. Sample name or dataset name are recommaded to present the order. Or user can just simply use `c(1,2,3...)` for a quick start.
```r
query <- process_obj(seulist = Inflorescence_query, seuorder = c("SRX13437605"), type = 'query')
reference <- process_obj(seulist = Inflorescence_ref, seuorder = c("SRX13437605"), type = 'reference')
```


## Prediction
Run scPlantGM for cell type prediction.
```r
result <- scPlantGM(query = query, reference = reference, species = "Arabidopsis", organ = "Inflorescence", 
                    custom = "Semi", layer_info = layer_info, layer = 2)
```
- `query`: a (list of) query Seurat object that you want to conduct prediction.
- `reference`: a (list of) Seurat object as reference.
- `species`: species of scRNA-seq data. You can choose 11 species in this mode, see `Species_Tissue` object for details.
- `organ`: organ/tissue of species. Available organs/tissues are listed in `Species_Tissue` object.
- `custom` = `Semi`.
- `layer_info`: a format-fixed data.frame includes layers information (will be ignored if custom='None'). A example shown in data/layer_info_example.rda.
- `layer`: layer of prediction: must be an int (0,1,2...). In `None` and `Semi` mode, user can choose one of built-in layer according to `layer_info_` object of the corresponding species.

The prediction result will be stored as a data.frame as follows:

## Advanced usage
scPlantGM wraps Seurat's `FindMarkers` function. Its default behavior is to take a clustered Seurat object and use `FindMarkers` to find top markers. Users can also run `FindMarkers` themselves and pass the resulting data.frames object directly via the `topmarkers_ref` and `topmarkers_query` arguments.
More comprehensive arguments of scPlantGM:
- `topmarkers_ref`: A data.frame, top markers of each cluster obtained from Seurat pipeline for reference Seurat object.
- `topmarkers_query`: A data.frame, top markers of each cluster obtained from Seurat pipeline for query Seurat object.
- `ref_clustername`: The column name specifying cluster identities in the reference Seurat objects. 
- `query_clustername`: The column name specifying cluster identities in the query Seurat objects.
- `topn`: A threshold for determining number of highly expressed gene will be used.
- `p_thres`: A threshold for determining what level of module purity is acceptable. The higher the value, the purer the module are.
- `m_thres`: A threshold for determining how many modules can be accepted. The higher the value, the more modules can be accepted.
- `x_thres`: A threshold for determining whether the cell type should be ‘unknown’.
- `cores`: Numbers of CPU for running.
